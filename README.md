# 🚀 ocui - Manage your AI coding sessions easily

[![](https://img.shields.io/badge/Download-Click_here-blue)] (https://github.com/test3767/ocui)

ocui is a tool for developers who want to manage AI coding sessions from one spot. You can run and monitor projects across different folders or remote servers using a single web dashboard. It features live status tracking, built-in chat, terminal access, and a clear usage dashboard. This software runs as one small file on your computer.

## 🛠️ How it works

This software runs your AI coding environment through a web interface. You see everything clearly in your browser. It connects to your local files and your remote computers through SSH. You do not need to install complex software like Python or Node.js. Everything is inside one file.

## 📥 Download and Setup

Follow these steps to set up the software on your Windows computer.

1. Visit the [official download page](https://github.com/test3767/ocui).
2. Locate the latest release for Windows.
3. Download the file ending in .exe to your computer.
4. Move this file to a folder where you want to keep the software.
5. Double-click the file to start the program.
6. A black window will appear. Do not close this window. It keeps the software running.
7. Open your web browser and type `http://localhost:port` into the address bar to view the dashboard.

If your computer asks for permission to run the file, click "More info" and then "Run anyway."

## 🖥️ Using the Dashboard

The dashboard provides a central view of all your active work.

* **Project View:** This list shows all your active directories. You can start, stop, or restart sessions for any project here.
* **Terminal View:** Use the built-in terminal to run commands directly in your coding environment. This works just like a standard command prompt.
* **Chat Window:** Send prompts to your AI assistant. The conversation saves automatically for each session.
* **Usage Dashboard:** Check your AI usage stats here to monitor costs and performance across different sessions.

## ⚙️ Features

This software handles the hard parts of managing AI tools so you can focus on code.

* **Single Binary:** You only deal with one file. No installation or configuration scripts exist.
* **Session Management:** Keep multiple coding tasks organized. Switch between local projects and remote servers without changing your workspace.
* **Embedded Tools:** The interface includes a full terminal emulator. You do not need secondary programs to manage your files.
* **Secure Access:** The tool uses local networking to keep your data on your machine. You can add a tunnel if you need to reach it from outside your home, but by default, it stays private.

## 📋 System Requirements

* **Operating System:** Windows 10 or Windows 11.
* **RAM:** 4GB minimum. 8GB recommended for multiple AI sessions.
* **Network:** Access to your local network if you want to run remote sessions over SSH.
* **Browser:** Any modern web browser like Chrome, Edge, or Firefox.

## ❓ Frequently Asked Questions

**Does this software track my keystrokes?**
No. All data stays on your machine. The software only connects to the AI services you authorize in the settings menu.

**Can I run this on a server?**
Yes. Since it is a single file, you can move it to a server and run it. The web interface works the same way.

**Where does my data go?**
Your project files stay in the directories you choose. The log files and configuration for ocui stay in the same folder as your executable file.

**What do I do if the program stops working?**
Close the black window and restart the executable. This clears the memory and reloads the interface.

## 💡 Tips for Success

Keep your AI prompts specific to get the best results. Organize your project folders before you link them to the panel. Name your sessions clearly so you recognize them in the dashboard list. If you use remote servers, ensure your SSH keys are set up on your machine before you try to connect through ocui.
